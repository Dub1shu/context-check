# Claude Code トークン節約ガイド

Claude Code のトークン消費を減らすための実践ガイド。利用上限に頻繁に達する、あるいはコストを抑えたい場合に使う。

トークン消費は入力した文章の長さだけでは決まらない。長いセッションで蓄積した会話やファイル、`CLAUDE.md`、MCP、思考量、サブエージェントの数がいずれも影響する。逆に、依頼を短くしすぎたり検証を省いたりすると、やり直しが増えて総消費は増える。

最初に試す3つ:

1. 無関係なタスクへ移るときは `/clear`
2. `/context` で常時読み込まれる情報を確認し、不要なものを外す
3. 通常作業は必要十分なモデルと effort を使い、難所だけ上げる
